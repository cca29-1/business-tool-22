# Carmel Sport — Unit 22 Business Lab

A standalone, interactive classroom practice tool for Pearson BTEC Level 3 Sport Unit 22.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example, `unit-22-business-lab`).
2. Select **Add file → Upload files**, then upload `index.html` to the **root** of the repository (not inside a folder). Commit changes.
3. Open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, and Folder to **/(root)**, then save.
4. The published URL will follow `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Technical notes

- No build process, hosting backend, access tokens or API keys required.
- The site saves working notes in each student's browser's localStorage; it does not transmit them to a server.
- Report export creates a Word-compatible `.doc` file locally in the browser.
- Inter font is requested from Google Fonts, with Arial fallback if offline.
- Fictional learning scenarios; not an official Pearson assessment.
